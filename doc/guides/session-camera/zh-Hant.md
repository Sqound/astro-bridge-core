## 工作階段與本機歷史

已連接的儀器卡片顯示已啟用的唯讀工作階段資料：操作、目標、帶單位的數值及資料經過時間。超過三個來源採樣週期後，數值會標記為最後讀數。「已暫停」表示觀察端讓出存取權，並不表示儀器停止。缺失值仍為未知。請在各設定檔中選擇資料。Seestar 疊加需要擁有者提供的金鑰；取得金鑰須明確操作，且網橋需要網際網路。更換金鑰不改變已儲存的監聽選擇。DWARF 僅提供連線資訊，一次只接受一個應用程式。

「開啟工作階段」顯示保留的圖表、影格數最大值、捨棄原因及環境。觀測曝光僅累加單張曝光時間不變時實際看到的保留影格增量。缺少基準、設定改變或重設會令總量不完整；最後單張曝光時間單獨顯示。圖表斜線表示沒有已配對應用程式下載原始讀數的記錄，不表示應用程式曾關閉。舊版或彙總稽核的涵蓋範圍仍未知。時鐘未經驗證時，時間為近似值，序列順序仍有效。最近事件限於 500 筆讀數和生命週期記錄。CSV/JSON 包含所有保留讀數，JSON 還含事件及讀取應用程式名稱。「設定 → 工作階段」設定夜數及 MiB 上限，以先達到的限制為準。降低上限可能移除舊資料。刪除無法復原，請先匯出再明確確認。只有具有遙測或管理權限的已配對應用程式可讀取工作階段，這些權限不控制儀器。沒有讀取應用程式時，歷史仍儲存在本機。

## 連接的相機與限制

Pi Zero W 和 Zero 2 W 僅用於連線與遙測。相機需要核准的 Pi 3/4 等級；實機相機驗收先從 Pi 3B 測試台開始。在「設定 → 相機」中明確啟用服務及探索。示範初始為空，插入按鈕僅新增本機模擬器。用戶端探索網橋並查詢每條連線的實際端點，使用者無需輸入儀器位址。Alpaca 探索僅在已確認的管理網路上回應，接聽端成功繫結後才顯示位址。

僅提供實體連接且受支援的相機。UVC 需要支援的擷取格式，以及擁有者透過 camera-calibration.json 校準像素間距；沒有校準編輯器。請依擁有者步驟保留其他項目，然後安全地重新插拔或重新啟動。依連接埠產生的 ID 不證明相機個體身分。UVC 擷取受限的亮度影像（GREY/Y16/YUYV），最大 1280×960，僅支援像素合併 1。較長請求會平均多個影格，並非真正連續長曝光。沒有曝光控制時，影格時長僅為標稱值。無快門相機不會製造暗影格。不附帶廠商 SDK，使用 SDK 的相機需要安裝受支援的驅動程式。2.4 GHz 大型影像傳輸可能較慢。支援的像素合併 2 只是初始設定，應用程式選擇會保留。

一次只有一個 Alpaca 用戶端擁有相機。ClientID 是協定編號，不是已配對應用程式身分；DHCP 名稱僅在位址與目前記錄完全符合時顯示。「允許此應用程式使用」需要明確同意釋放目前顯示的使用者，可能中斷曝光。使用者改變會使舊同意失效。釋放後，另一應用程式必須重新連接，不會自動分配新使用者。反覆斷線提示檢查纜線及有供電的集線器，並不證明電壓故障。真實相機與手機行為、Pi 效能及 ConformU 驗收仍為**已文件化，尚未實機驗證**，另見 USB 限制。
